管理画面

Admin← サイトに戻る
1. テンプレートを配る酒蔵さんに「掲載データ入力シート」を送り、記入してもらいます。
入力テンプレートを保存
2. Excelを取り込んで確認取り込んだ内容は、このパソコンのブラウザ内で作業中として保存されます。「確認」でサイト上の見え方を確かめます。
3. 公開用データを保存してGitHubへ「公開用データを保存」で breweries.json を保存し、GitHub の data フォルダに上げると1〜2分でサイトに反映されます。

取り込みのルール

    変更はありませんサイトに公開中のデータと同じです。
    保存した breweries.json をGitHubに上げると公開されます
    1. GitHub で dd-japan リポジトリを開き、data フォルダに入ります。
    2. 「Add file」→「Upload files」を選び、保存した breweries.json をドラッグします。
    3. 下の「Commit changes」を押します。1〜2分ほどでサイトに反映されます。

    酒蔵の一覧

    公開中の酒蔵がひとつもない間は、サイトに見本（架空データ）が表示されます。
